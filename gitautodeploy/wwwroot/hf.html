Hugging Face Connection Check

Documentation: Git-HF-Deployment

This application is modified to work exclusively with Hugging Face Spaces and integrate with the Jules agent for automated fixes.

  • Webhook Flow:
    1. GitHub sends a push webhook to this server.
    2. This server pulls the latest changes from GitHub.
    3. It then runs scripts/deploy_to_hf.py to sync those changes to Hugging Face Spaces.
    4. The script polls the HF API to monitor build and runtime health.
  • Jules Auto-Fix: If the HF deployment fails, a GitHub issue is created with the jules:run label. Jules picks this up, fixes the error, and pushes back to GitHub, triggering a new successful deploy.
  • Web UI: Monitor real-time webhook events and check connection parameters here.
